# tld-jump

**A jump for The Long Dark, using the jump the game already has.**

MelonLoader mod. Press the key, the character jumps. Default key is `V`.

## Why this can work at all

The player is driven by `vp_FPSController`, which is UFPS, and UFPS jumps. The evidence is in the
interop assembly the loader generates, not in anybody's opinion:

    public bool Jump()                  the controller's own jump, public, returns whether it took
    public float MotorJumpForce         how hard it pushes
    public bool m_WasGroundedLastFrame  whether there is ground under the feet
    public bool IsFreeFalling()

So this mod does not invent a jump. It calls the one that is already there, which is why the arc,
the landing, the fall damage and the footstep should all behave like the game's own - because they
are the game's own.

**Why other jump mods look wrong.** Shoving the character upward by writing to velocity or to the
transform fights the controller rather than using it: the controller keeps its own idea of speed and
grounding, so the result floats, snaps back, or lands without ever having fallen. Calling `Jump()`
hands the problem back to the system that owns it.

## What is not yet known

IL2CPP gives signatures and no method bodies, so `Jump()` can be *called* but its behaviour cannot
be *read*. It may work perfectly, it may be gated on conditions this mod has not met, or the jump
force may be zero - which is the most likely way jumping was removed from a game that clearly has
the machinery for it.

That is why the mod measures rather than assumes:

- if the controller refuses, the log says so and prints the grounded flag and the force
- every jump reports how high it actually rose, and calls out anything under five centimetres as
  not a jump

One press answers all of it.

## Settings

`UserData\MelonPreferences.cfg`, category `TLDJump`.

| Setting | Does | Default |
|---|---|---|
| `Key` | The jump key. | `V` |
| `JumpForce` | How hard the push is, in the controller's units. Walking acceleration is about 0.03 for scale. | `0.14` |
| `UseOwnForce` | Write `JumpForce` into the controller before jumping, because the game's own is likely zero. | on |
| `CooldownSeconds` | Least time between jumps, so a held key is not a hover. | `0.35` |
| `RequireGround` | Only jump with ground underfoot. | on |
| `ReportHeight` | Log how high each jump actually went. | on |

**A note on the key.** `Space` would be the natural jump key and is deliberately NOT the default: The Long Dark uses it for its context menu, so it would open something on every jump. If
it opens something as well as jumping, rebind to `V`. Modifiers do not help - the game does not
check them, which was established the hard way when three of another mod's hotkeys turned out to be
the game's screenshot keys.

## Building

    dotnet build tld-jump.csproj -c Release

References come from the game install. The interop assemblies under `MelonLoader\Il2CppAssemblies`
are generated by MelonLoader on its first successful launch.
